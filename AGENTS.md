# AGENTS.md — shoptify

> Project chip. Read this before touching the vault.

## Goal
Offline study archive of the Shopify Editions Winter '26 page: captured front-end assets,
a readable index, and a reusable design analysis. Not a product, not a clone.

## Stack
- Static site: vanilla HTML/CSS/JS (`site/`), data injected via `site/data.js`.
- Mirror: the captured SSR document + bundles, running in place (`mirror/`).
- Capture: Python 3 (stdlib + Pillow) + Camofox MCP / CLI.
- Fonts served locally from `assets/fonts/`; no external requests at runtime.

## Commands
```bash
# the reading interface
python3 -m http.server 4173      # http://127.0.0.1:4173/site/

# the page itself (must answer on /editions/winter2026)
python3 scripts/build_mirror.py     # regenerate mirror/ from the capture
python3 scripts/serve_mirror.py 4174  # http://127.0.0.1:4174/editions/winter2026

# regenerate data + docs after a re-capture
python3 scripts/build_site_data.py
python3 scripts/build_docs.py
```

## Map
- `site/index.html` — structure (sections 00–06)
- `site/studio.css` — tokens, layout, components, responsive rules
- `site/app.js` — render, chapter reader, asset filters, lightbox, Ctrl+E palette
- `site/data.js` — generated; never hand-edit
- `mirror/index.html` — generated by `scripts/build_mirror.py`; the live page itself
- `mirror/{js,css}` — rewritten bundles; `mirror/assets`, `mirror/vendor` are symlinks
- `vendor/` — npm files the bundles load at runtime (Rive wasm, KTX2 transcoder)
- `assets/` — captured CDN files (read-only evidence)
- `snapshot/` — SSR HTML, screenshots, `page-content.json`, `inventory.json`
- `docs/` — the written analysis (source of truth for findings)

## Rules
1. Do not edit files in `assets/`; they are evidence. Re-capture instead.
2. `site/data.js` is generated by `scripts/build_site_data.py`.
3. Keep `site/` original. Never paste Shopify CSS/JS into `site/`; `mirror/` is the
   only place the captured bundles run, and it is generated, never hand-edited.
4. Any new claim in docs must trace back to `snapshot/page-content.json` or the CSS/JS bundles.
5. Preserve the legal notice in `README.md` and `docs/05-asset-ledger.md`.

## Design DNA for this project
Paper `#F7F7EE`, ink `#292919`, edition pink `#EA1360`, hairlines instead of shadows,
display type at negative tracking, four UI states (empty / loading / error / populated),
`Ctrl+E` command palette, `prefers-reduced-motion` respected.
