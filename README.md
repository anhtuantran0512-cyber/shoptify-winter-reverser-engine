# SHOPTIFY — Winter '26 study vault

A local field archive of **Shopify Editions · Winter '26** (`shopify.com/editions/winter2026`), captured through the browser's own DevTools surface and rebuilt into something readable.

This is a **study project**. Page copy, imagery, fonts and bundles belong to Shopify Inc. and stay here for analysis only — see [Scope](#scope).

---

## What is inside

| Path | Contents |
|---|---|
| `mirror/` | The page itself: captured SSR document + bundles + rewritten URLs, running locally with its scroll, WebGL and video behaviour |
| `site/` | Original interface for browsing the archive (paper/ink editorial design, chapter reader, asset vault, Ctrl+E palette) |
| `assets/` | CDN resources the page served: JS chunks, compiled CSS, fonts, 27 Rive files, ~554 images, 37 GLB models, film loops |
| `snapshot/` | SSR HTML, per-section screenshots, full page content model, resource inventory, capture log |
| `docs/` | Teardown, design system, information architecture, motion analysis, asset ledger |
| `scripts/` | Reproducible capture → inventory → download → build pipeline |
| `src/` | Reusable token sheet and two components distilled from the analysis (original code) |

Counts and sizes are regenerated by `scripts/build_docs.py` and `scripts/build_site_data.py`.

## Open

```bash
cd "./Documents/Study Archive/projects/shoptify"

# the mirror — the original page, running locally
python3 scripts/serve_mirror.py 4174
# http://127.0.0.1:4174/editions/winter2026

# the reading interface over the archive
python3 -m http.server 4173
# http://127.0.0.1:4173/site/
```

The mirror has to answer on `/editions/winter2026` because the app matches that
path against its route table; `serve_mirror.py` does that, `http.server` cannot.
A server is also required for `site/` (fonts, images and `data.js` are loaded
relative). `Ctrl+E` opens the command palette.

Reference frames of both surfaces live in `snapshot/screenshots/`:
`00-hero.png` … `12-developer.png` are the source page, `vault-*.png` are this interface.

## The five findings worth keeping

1. **Neutral interface, chromatic art.** The UI is `#F7F7EE` on `#292919` with hairlines; all colour comes from the paintings. One pink accent does the shouting.
2. **Two type roles, strictly graded.** A geometric grotesque (NeueMontreal) for structure, a serif (HWCigars) for voice. UI text never competes.
3. **Subgrid alignment.** Feature cards inherit the headline's 12-column tracks; nothing drifts.
4. **Scroll as timeline.** 46,000 px, twelve chapters, Lenis + IntersectionObserver + Rive + View Transitions, with `detect-gpu` deciding how much to render.
5. **It is a real storefront.** The Remix manifest includes `cart`, `merch` and `video/:handle` — the campaign page sits inside a commerce app, not a static site.

Full reasoning: `docs/01-teardown.md` and `docs/02-design-system.md`.

## The mirror

`mirror/` is the page itself rather than a reading of it. The captured document
is served with the captured bundles, so the scroll-driven scenes, the KTX2
stage, the Theatre.js timelines, the Rive animations and the film loops are the
originals — nothing was re-implemented.

Measured in the same browser, frame by frame: identical document height
(48 281 px), identical section offsets, three live WebGL canvases at the same
scroll position, and 0 % pixel difference in four of six sampled frames. The two
differing frames contain a rotating globe caught at a different animation phase.

Build, serving and the resource gaps that had to be filled are documented in
[`docs/06-mirror.md`](docs/06-mirror.md).

## Reproduce

```bash
camofox open "https://www.shopify.com/editions/winter2026"
python3 scripts/extract_page.py <tabId>
python3 scripts/build_inventory.py
python3 scripts/capture_assets.py snapshot/inventory.json assets
python3 scripts/build_site_data.py
python3 scripts/build_docs.py
```

Requirements: Python 3.10+, Pillow, Camofox on `127.0.0.1:9377`. Only public front-end resources are requested — no auth, no private endpoints, no paywall circumvention.

## Scope

- **This is** a local mirror of files a normal browser already downloaded, plus original analysis and an original interface.
- **This is not** a Shopify clone, template, or redistribution. Imagery, copy, fonts and bundles remain Shopify Inc. property. Do not ship them in a product.
- **Reuse the thinking**, not the assets: palette logic, type scale, chapter model, motion budget, capture pipeline.
