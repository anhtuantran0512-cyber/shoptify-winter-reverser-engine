      How the capture was made

      1. 01

        Open the page in Camoufox, then read performance.getEntriesByType('resource') — the DevTools Network panel, expressed as JavaScript.

      2. 02

        Walk the live DOM for chapters, feature copy, CTAs and media. Serialize the SSR HTML as a second witness.

      3. 03

        Download the public CDN files the page already served to the browser. Images are re-requested at width=700 to keep the vault light.

      4. 04

        Parse the compiled stylesheet for tokens, then rebuild this index from the JSON instead of retyping anything.

      No authentication, paywall or private endpoint was touched. If the browser could render it, it is in assets/.

            06
            
      
            
        
            Scope & conscience
            
        
            A study vault is only useful if it is honest about what it is.
            
      
            
    
            
    
            
      
            
        
            What this is
            
        
            A local mirror of resources the page sent to a normal browser, plus original analysis and an original index interface. Built to learn layout, motion and information architecture.
            
      
            
      
            
        
            What this is not
            
        
            Not a Shopify clone, not a template, not a redistribution. Imagery, copy, fonts and bundles remain Shopify Inc. property. Do not ship them in a product.
            
      
            
      
            
        
            What to reuse
            
        
            The thinking: paper-and-ink palette, one saturated accent, editorial type scale, chapter rail, sticky scenes, restrained easings. Rebuild those with your own assets.
            
      
            
      
            
        
            Freshness
            
        
            Captured once. CDN hashes change with every deploy, so treat filenames as a timestamp, not an API.
