# src — reusable output

Original code distilled from the study. None of it is copied from Shopify.

- `shoptify-tokens.css` — colour, type roles, spacing, radii, motion durations.
- `components.css` — chapter rail, feature card, editorial lockup, skeleton/empty states.
- `components.html` — visual lab. Open it directly or through the local server.

Usage:

```html
<link rel="stylesheet" href="shoptify-tokens.css">
<link rel="stylesheet" href="components.css">
```

The token sheet expects the three font families to be available (any licensed
equivalents will do — the roles matter more than the exact typefaces).
